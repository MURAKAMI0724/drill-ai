# こども向け専用アプリへの全面リニューアル 依頼書

このアプリを **未就学児〜小学校低学年 専用の学習あそびアプリ** に作り替えます。

あわせてデザインを、ダーク×ゴールドの大人向けから**明るいこども向け**へ全面刷新します。

## 3. デザインシステム

### 3-1. フォント

`next/font/google` で **M PLUS Rounded 1c**(weight 400 / 700 / 800)を読み込み、
アプリ全体の既定フォントにしてください。丸ゴシックは幼児の可読性が高く、
Google Fonts で日本語に対応している数少ない選択肢です。

```
fallback: "Hiragino Maru Gothic ProN", "Yu Gothic", system-ui, sans-serif
```

### 3-2. カラートークン

`globals.css` の既存トークン(`--bg` `--gold` など)を**すべて置き換え**、
Tailwind を使っている場合は `tailwind.config` の `theme.extend.colors` にも登録して、
色をハードコードしないでください。

```css
:root{
  /* そら(背景) */
  --sky-top:#bfe9fb;
  --sky-bottom:#e8f7ff;
  --surface:#ffffff;

  /* もじ */
  --ink:#233457;      /* 本文 */
  --ink-sub:#4a5a78;  /* 補助 */

  /* せいかい・ざんねん */
  --good:#127a41;
  --bad:#c62f27;

  /* モードごとの アクセント原色 と そのうすい色 */
  --c-calc:#f97316; --t-calc:#feebde;  /* さんすう */
  --c-siri:#12a5a0; --t-siri:#def2f2;  /* しりとり */
  --c-nazo:#e94f8a; --t-nazo:#fce6ef;  /* なぞなぞ */
  --c-naka:#e0930a; --t-naka:#fbf0dd;  /* なかまはずれ */
  --c-toke:#2f7fd4; --t-toke:#e2edf9;  /* とけい */
  --c-naki:#2f9e56; --t-naki:#e2f1e7;  /* なきごえ */
  --c-hant:#e04a52; --t-hant:#fbe6e7;  /* はんたい */
  --c-okan:#b8860b; --t-okan:#f5eedd;  /* おかね */
  --c-koto:#7c5cd6; --t-koto:#ede8f9;  /* ことわざ */

  --radius-tile:28px;
  --radius-btn:22px;
  --shadow-tile:0 4px 0 rgba(35,52,87,.10), 0 10px 24px rgba(35,52,87,.10);
  --shadow-press:0 1px 0 rgba(35,52,87,.10), 0 4px 10px rgba(35,52,87,.10);
}
```

### 3-3. 色の使い方(この規則を必ず守ること)

これは見た目の好みではなく、**読みやすさを保証するための規則**です。
上の配色は WCAG のコントラスト比を実測して決めています。

- **文字は つねに `--ink`(濃紺)**。白カード上で 12.35:1、そら背景上で 9.57:1。
- **タイルやカードの背景は 白 か `--t-*`(うすい色)**。`--ink` との比は全モードで 10:1 以上。
- **`--c-*`(ビビッドな原色)は「絵文字のうしろの まる」「帯」など装飾だけに使う。**
  原色の上に白文字を乗せると、オレンジ 2.80:1・イエロー 2.52:1 のように
  **コントラスト不足で子どもには読めません**。原色の上に文字を置かないでください。
- `--good` / `--bad` は 5.4:1 なので、文字色にも白文字の背景にも使えます。

### 3-4. サイズ・余白

こどもは指が小さく、狙ったところをタップできません。**大きく作ること**が最優先です。

- タップできる要素は **最小 高さ 60px**、メニュータイルは **最小 高さ 132px**
- 選択肢ボタンは **高さ 64px 以上・フォント 20px 以上・太字(800)**
- 問題文は **24〜28px の太字**
- タイルどうしの間隔は 14px、画面の左右余白は 18px
- 角丸は タイル 28px / ボタン 22px / カード 30px。四角い角は使わない

### 3-5. アニメーション

- ボタン・タイルを押したとき: `transform: translateY(3px) scale(.985)` + 影を浅く(0.12秒)
- 正解時: 紙吹雪(confetti)を 1秒ほど散らす。ライブラリを足さず、
  CSSアニメーションと絵文字(🎉✨⭐)で軽く実装してください
- 不正解時: カードを左右に小さく揺らす(0.4秒、振れ幅 6px程度)
- **必ず `@media (prefers-reduced-motion: reduce)` で全アニメーションを無効化してください**
  (前庭障害のある子・感覚過敏の子への配慮です)

## 4. ホーム画面(トップメニュー)

`src/app/page.tsx` のルートを、起動直後にこのホーム画面が出るように変更してください。

### レイアウト(上から順に)

1. **ヘッダー**(左から)
   - ロゴ: 48px角の丸角スクエア。`linear-gradient(150deg,#ffd166,#ff8fab 55%,#8ecae6)` に 🌸
   - アプリ名「こどもアプリ」(800 / 21px)、その下に小さく「あそんで まなぼう」
   - 右端に ⭐ の獲得数チップ と 🔊/🔇 トグル(どちらも 46px角、白背景・丸角)
2. **あいさつ**: 「きょうは なにで あそぶ?」(15px / 700 / `--ink-sub`)
3. **メニュータイル**: **2列グリッド**でセクション2の9つを並べる
   - タイル背景 = そのモードの `--t-*`
   - 左上に 56px角の丸角スクエア(背景 = `--c-*`)、中に絵文字を 30px で
   - その下に モード名(18px / 800)、説明文(12px / 700 / `--ink-sub`)
   - `<button>` で作り、`aria-label` に「さんすう。たしざん・ひきざん」のように入れる

### 背景

`linear-gradient(180deg, var(--sky-top) 0%, var(--sky-bottom) 55%, #f4fbff 100%)` の上に、
白い半透明の円を `radial-gradient` で数個ちらして、そらに浮かぶ花・雲のようにしてください
(`opacity: .5` 程度。うるさくしないこと)。

### 音声

ホームに入ったとき、音声ONなら「きょうは なにで あそぶ?」と1回だけ読み上げてください。
画面を再訪するたびに毎回しゃべるとうるさいので、**そのセッションで初回だけ**にします。

## 5. 共通レイアウト部品

9モードで見た目がバラバラにならないよう、**共通コンポーネントを作ってから**各モードを載せ替えてください。

### `<GameLayout>`
- props: `title`(モード名)、`accent`(`--c-*` の値)、`tint`、`onBack`、`progress`(0〜1)、`children`
- 上部に 戻る(←)ボタン・モード名・⭐チップ・🔊トグル
- その下に 進捗バー(高さ14px・丸型・`linear-gradient(90deg,#ffd166,#ff8fab)`)
- 背景は ホームと同じ そらグラデーション

### `<QuestionCard>`
- 白背景・角丸30px・影つきのカード。中に 小さなラベル(例「いま なんじ?」)と問題本体

### `<ChoiceButton>`
- 白背景・3px の白枠・角丸22px・高さ64px以上
- 左に 34px角の番号バッジ(1/2/3)、右に選択肢テキスト(20px / 800)
- 状態: 通常 / `correct`(枠 `--good`・背景 `#eaf7ef`・バッジ緑地に白文字) /
  `wrong`(枠 `--bad`・背景 `#fdeceb`)
- **色だけで正誤を伝えないこと。** 正解には ⭕、不正解には ✕ のマークも必ず添えてください
  (色覚特性のある子でも判別できるようにするためです)

### `<HintButton>`
- 背景 `#fff8dc`、文字 `#7a5c00`、「💡 ヒントを みる」

### `<FeedbackBanner>`
- 正解: 背景 `#eaf7ef`・文字 `--good`・「🎉 せいかい!」
- 不正解: 背景 `#fdeceb`・文字 `--bad`・「✕ ざんねん! もういちど」

## 6. 各モードの載せ替え

既存の9つの画面コンポーネントを、上の共通部品を使う形に書き換えてください。
**ゲームのロジック(判定・出題プール・音声・タイマー)は一切変えないこと。**
見た目とレイアウトだけを差し替えます。

- 各モードには セクション3-2 の対応する `--c-*` / `--t-*` を割り当てる
- 文字はすべて **ひらがな**。漢字は使わない
  (ことわざの本文だけは例外。漢字のまま表示し、読み上げでフォローします)
- 進捗バーは「そのモードで今回何問やったか / 10問」を目安に表示してください

## 7. ごほうび(⭐スター)

こどもが続けたくなる仕組みを入れます。

- 正解するたびに ⭐ を1つ獲得。ヘッダーのチップの数字が増える
- 獲得時、チップが 1.3倍に跳ねて戻るアニメーション
- 累計を `localStorage`(キー: `kodomo-app-stars`)に保存
- 10個たまるごとに「⭐が 10こ たまったよ! すごい!」と表示・読み上げ

> **必ず守ること(ありがちなバグ)**
> `localStorage` はサーバー側に存在しないため、レンダー中に読むと
> Next.js で **hydration mismatch エラー**になります。
> 初期値は必ず `0` にして、`useEffect` の中で読み込んで state を更新してください。

- アプリ名は **「こどもアプリ」**。`src/lib/constants.ts` などに定数として持たせ、
  1か所変えれば全画面に反映されるようにしてください

  - `description`: 「さんすう・しりとり・なぞなぞ・とけいなど、9つのあそびで たのしく まなべる こども向けアプリ」

- `src/app/icon.png` は配置済みなのでそのまま使ってください
- `public/manifest.json` を作成し、PWA としてホーム画面に追加できるようにしてください
  - `name` / `short_name`: こどもアプリ
  - `display`: `standalone`、`background_color`: `#e8f7ff`、`theme_color`: `#bfe9fb`
  - アイコンは `icon.png` を 192/512 で参照
- README を新しいアプリの内容に書き換えてください(APIキー不要になった旨も反映)
